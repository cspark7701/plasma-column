Executive Overview & System Architecture

Project Author: Chong Shik Park • Department of Accelerator Science and Center for Accelerator Research, Korea University, Sejong, 30019 Republic of Korea.

High-current (\(30\text{ keV}\), \(10\text{ mA}\)) proton beams in compact cyclotron Low-Energy Beam Transport (LEBT) lines experience strong uncompensated space-charge perveance (\(K_0 \approx 6.43 \times 10^{-4}\)), causing rapid beam envelope expansion, emittance growth, and heavy transmission loss at the entrance aperture of the spiral inflector.

This project evaluates a compact gas-ionized plasma neutralizer cell placed upstream of the primary solenoid lens to achieve high space-charge compensation (\(\eta_{\text{net}} \ge 90\%\)).

Baseline Injection Line Geometry

buncher → plasma neutralizer → solenoid → quadrupole Q1 → quadrupole Q2 → spiral inflector

Physics Models & Ionization Kinetics

Impact Ionization Kinetics

Proton-impact collisions generate secondary electron-ion pairs in the gas cell:

\[ p^+ + \text{Gas} \longrightarrow p^+ + \text{Gas}^+ + e^- \]

Secondary electrons are trapped in the beam's space-charge potential well, while ions are repelled radially.

Buildup Time Constant

The space-charge neutralization buildup time constant \(\tau\) is defined as:

\[ \tau = \frac{1}{n_{\text{gas}} \sigma_{\text{ion}} v_{\text{beam}}} \]

Buildup kinetics follow: \(\eta(t) = \eta_{\text{ss}} (1 - e^{-t/\tau})\)

RF-Bunched Beam Space-Charge Perveance Limit: When an RF buncher is upstream of the neutralizer, the beam enters the plasma cell already bunched with bunching factor \(B_f = I_{\text{peak}} / I_{\text{avg}}\). While background electrons provide average neutralization \(\eta_{\text{avg}}\), peak-bunch space charge is reduced by:

\[ \frac{K_{\text{eff,peak}}}{K_{0,\text{peak}}} \approx 1 - \frac{\eta_{\text{avg}}}{B_f} \]

Full Production Simulation & Analysis Pipeline

Pipeline Overview: Automated end-to-end simulation, post-processing, figure generation, summary table compilation, dataset freezing, and downstream optics transport analysis in a single reproducible command (run_full_production.sh) or Jupyter notebook (nb_full_production_pipeline.ipynb).

Execution Flow & 8 Production Stages

The production pipeline executes eight structured stages sequentially:

Stage Description & Purpose Shell Command / Script Output Log / Deliverables
1. Audit Environment audit (Conda, PyWarpX, Python packages, git commit hash, WarpX C++ source diff) python3 scripts/print_environment.py logs/step_1_8.log
2. Scan Setup Matrix scan setup & parameter validation across 9 cases (vacuum, static seeded, callback, C++ MCC) python3 scripts/run_scan.py --matrix cases/method_comparison.yaml logs/step_2_8.log, results/*/config.yaml
3. Baseline Run Baseline PIC simulation case verification & execution for H₂ / Kr neutralizer cells python3 scripts/run_case.py --case cases/baseline_h2.yaml logs/step_3_8.log, results/*/metadata.json
4. Post-Process Extract particle count metrics \(N_p, N_e, N_i\), global \(\eta\), local core density, and \(K_{\text{eff}}/K_0\) python3 scripts/postprocess_case.py --case-dir results/seeded_H2_baseline logs/step_4_8.log, local_neutralization.csv
5. Figures Generate publication figures (cross sections \(\sigma(E)\), buildup curves, spatial density profiles, envelope) python3 scripts/make_plots.py & make_paper_figures.py logs/step_5_8.log, plots/, paper/figures/
6. Tables Compile CSV paper summary tables and freeze canonical publication dataset manifest python3 scripts/make_paper_tables.py & freeze_publication_dataset.py logs/step_6_8.log, paper/tables/, dataset_manifest.json
7. Optics Model RF-bunched beam peak perveance reduction and simulate transport to spiral inflector python3 scripts/analyze_bunched_beam_neutralization.py & transport_to_inflector.py logs/step_7_8.log, beam_envelope.csv
8. Audit Final repository integrity audit (code compileall, pytest, metadata schemas, docs verification) python3 scripts/audit_repo.py --root . logs/step_8_8.log

Command Line Options & Token-Conserving Execution

Execute the pipeline from the repository root using the shell script or root wrapper:

# Standard quiet execution (displays real-time [RUNNING] step indicators, redirects logs to logs/):
./run_full_production.sh

# Dry-run mode (validates all configurations, matrices, & metadata without heavy PIC steps):
./run_full_production.sh --dry_run

# Verbose mode (prints full execution logs directly to terminal screen):
./run_full_production.sh --verbose

# Custom parallel CPU core allocation (e.g. 80%):
./run_full_production.sh --cpu-pct 80

Parallel Hardware Scaling (~90% CPU Allocation)

The script automatically detects system hardware cores and configures target multi-threading OpenMP environment variables:

\[ \text{Target Cores} = \left\lfloor \text{nproc} \times \frac{\text{CPU\_PCT}}{100} \right\rfloor \]

Automatically exports: OMP_NUM_THREADS, OPENMP_NUM_THREADS, MKL_NUM_THREADS, and NUMEXPR_NUM_THREADS.

Literature Review & Technical Context

  • Cyclotron Axial Lines: Jongen (1981), Kazarinov (2007, 2010) identified severe space-charge limits in high-current injector lines. Retarding Field Analyzer (RFA) tests by Winklehner et al. (2013, 2014) showed 60%–95% neutralization in ECR LEBTs.
  • Electron Columns & Lenses: Space-charge compensation experiments at IOTA (Park 2019, 2020; Freemire 2018; Stancari 2016, 2021) demonstrated controlled electron trapping to counteract proton space charge.
  • Gabor Plasma Lenses: Palkovic (1988) tested Gabor lenses for 30 keV protons; Nonnenmacher (2021) documented Diocotron plasma instabilities.
